# התקנת VgoOffice

[גרסאות](https://github.com/vgo1012/VgoOffice/releases) — השתמשו במתקין המצורף לגרסה. עמוד זה אינו מעיד שקובץ בינארי כבר פורסם ב-GitHub. בניות מקומיות אינן חתומות ללא פרטי חתימה.

## לפני ההתקנה

מהדורה זו נבדקה ב-Windows x64. יעדי הקוד עבור macOS ו-Linux נשמרו, אך מהדורה זו לא אומתה בהם. בחרו חבילה רק כשהגרסה מציינת תמיכה במערכת ההפעלה שלכם.

## התקנה והפעלה

1. שמרו מסמכים פתוחים וסגרו את הגרסה הקודמת לפני השדרוג.
2. הפעילו את מתקין ה-.exe של Windows והשלימו את ההתקנה.
3. הפעילו את VgoOffice מקיצור הדרך בשולחן העבודה או בתפריט התחל.

המתקין שומר משאבים פעם אחת, ללא פריסה של תוכנה ניידת בכל הפעלה. העתקת VgoOffice.exe בלבד אינה כוללת את משאבי העורכים הדרושים.

## שדרוג והעדפות

השדרוג שומר על זהות ההתקנה ועל תיקיית הפרופיל Eoffice. שם תיקייה שנשאר Eoffice הוא תקין לתאימות. בהגדרות → כללי בחרו מראה בהיר, כהה או לפי המערכת; הרקע הוא כחול-אפור בהיר כברירת מחדל. צבעי המסמכים נשלטים בנפרד.

## הגרסה והפרויקט

הגדרות → אודות מציגות את הגרסה המותקנת וקישור ל-VgoOffice. תנו למאגר Star אם הוא מועיל. עדכונים תלויים בתצורת הבנייה; בדקו את עמוד הגרסאות אם אין עדכון באפליקציה.

[VgoOffice · Star](https://github.com/vgo1012/VgoOffice)

## שורת פקודה ו-AI

פקודת התאימות נשארת genoffice. הגדרות → שילובים מציגות את נתיב ההתקנה ואת התצורה. הפעילו את הפקודה דרך הנתיב או לאחר הוספת CLI ל-PATH.

```sh
genoffice --version
```

הכניסה לחשבון האפליקציה הוסרה. הגדירו API מודלים משלכם, נקודת קצה תואמת OpenAI או Codex CLI מותקן. אימות חיצוני ותשלום נפרדים; עריכה מקומית אינה דורשת חשבון VgoOffice.
