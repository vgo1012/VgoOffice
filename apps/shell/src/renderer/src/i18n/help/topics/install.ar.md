# تثبيت VgoOffice

[الإصدارات](https://github.com/vgo1012/VgoOffice/releases) — استخدم ملف تثبيت مرفقًا بإصدار. لا تعني هذه الصفحة أن ملفًا تنفيذيًا نُشر بالفعل على GitHub. تبقى البناءات المحلية غير موقعة ما لم تُوفر بيانات اعتماد للتوقيع.

## قبل التثبيت

تم التحقق من هذا الإصدار على Windows x64. تبقى أهداف الشفرة لنظامي macOS وLinux، لكن لم يتم التحقق من هذا الإصدار عليهما. اختر حزمة فقط إذا كان إصدارها يدعم نظام التشغيل لديك صراحةً.

## التثبيت والتشغيل

1. احفظ المستندات المفتوحة وأغلق الإصدار السابق قبل الترقية.
2. شغّل ملف التثبيت .exe الخاص بنظام Windows وأكمل التثبيت.
3. ابدأ VgoOffice من اختصار سطح المكتب أو قائمة ابدأ.

يحفظ المثبّت الموارد مرة واحدة، فلا يلزم فك ضغط برنامج محمول عند كل تشغيل. نسخ VgoOffice.exe وحده لا يتضمن موارد المحررات المطلوبة.

## الترقية والتفضيلات

تحتفظ الترقية بهوية تثبيت Eoffice ومجلد الإعدادات الموجود. استمرار اسم المجلد Eoffice أمر طبيعي للتوافق. اختر المظهر الفاتح أو الداكن أو مظهر النظام من الإعدادات → عام؛ الخلفية الافتراضية زرقاء رمادية فاتحة. تُضبط ألوان المستندات بشكل منفصل.

## الإصدار والمشروع

تعرض الإعدادات → حول الإصدار المثبّت ورابط مشروع VgoOffice. أضف Star للمستودع إذا كان مفيدًا. توفر التحديثات يعتمد على إعداد البناء؛ راجع صفحة إصدارات المشروع عند غياب التحديث داخل التطبيق.

[VgoOffice · Star](https://github.com/vgo1012/VgoOffice)

## سطر الأوامر والذكاء الاصطناعي

يبقى أمر التوافق genoffice. تعرض الإعدادات → التكاملات مسار التثبيت وإعداد التكامل. نفّذ الأمر التالي باستخدام ذلك المسار أو بعد إضافة CLI إلى PATH.

```sh
genoffice --version
```

أزيل تسجيل الدخول إلى حساب التطبيق. اضبط API النماذج الخاص بك أو نقطة اتصال متوافقة مع OpenAI أو Codex CLI المثبت. تبقى مصادقة الخدمات الخارجية ورسومها مستقلة؛ لا يحتاج التحرير المحلي إلى حساب VgoOffice.
