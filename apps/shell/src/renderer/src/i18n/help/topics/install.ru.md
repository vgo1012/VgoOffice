# Установка VgoOffice

[Выпуски](https://github.com/vgo1012/VgoOffice/releases) — Используйте установщик, прикреплённый к выпуску. Эта страница не означает, что бинарный файл уже опубликован на GitHub. Локальные сборки не подписаны, если не заданы данные для подписи.

## Перед установкой

Эта версия проверена на Windows x64. Целевые платформы macOS и Linux сохранены в исходном коде, но эта версия на них не проверена. Выбирайте пакет только при явной поддержке вашей системы в описании выпуска.

## Установка и запуск

1. Сохраните открытые документы и закройте предыдущую версию перед обновлением.
2. Запустите установщик .exe для Windows и завершите установку.
3. Запустите VgoOffice с ярлыка на рабочем столе или в меню «Пуск».

Установщик сохраняет ресурсы один раз, без повторной распаковки переносимого приложения при каждом запуске. Копирования только VgoOffice.exe недостаточно: нужны ресурсы редакторов.

## Обновление и настройки

Обновление сохраняет идентификатор установки и каталог профиля Eoffice. Старое имя каталога Eoffice нормально и нужно для совместимости. В разделе Настройки → Общие выберите светлую, тёмную или системную тему; стандартный фон — светлый серо-голубой. Цвета документов настраиваются отдельно.

## Версия и проект

Настройки → О программе показывает установленную версию и ссылку на проект VgoOffice. Поставьте Star, если проект полезен. Обновления зависят от конфигурации сборки; если они недоступны в приложении, проверьте страницу выпусков проекта.

[VgoOffice · Star](https://github.com/vgo1012/VgoOffice)

## Командная строка и ИИ

Команда совместимости остаётся genoffice. Настройки → Интеграции показывает путь установки и параметры интеграций. Запустите следующую команду по этому пути или после добавления CLI в PATH.

```sh
genoffice --version
```

Вход в учётную запись приложения удалён. Настройте свой API моделей, адрес, совместимый с OpenAI, или установленный Codex CLI. Внешняя авторизация и плата за использование остаются отдельными; для локальной работы учётная запись VgoOffice не нужна.
