# ติดตั้ง VgoOffice

[รุ่นเผยแพร่](https://github.com/vgo1012/VgoOffice/releases) — ใช้ตัวติดตั้งที่แนบกับรุ่นเผยแพร่ หน้านี้ไม่ได้หมายความว่าเผยแพร่ไฟล์โปรแกรมบน GitHub แล้ว การสร้างบนเครื่องจะไม่มีลายเซ็นหากไม่ได้ระบุข้อมูลรับรองสำหรับการลงนาม

## ก่อนติดตั้ง

รุ่นนี้ได้รับการตรวจสอบบน Windows x64 แล้ว โค้ดยังคงมีเป้าหมายสำหรับ macOS และ Linux แต่ยังไม่ได้ตรวจสอบรุ่นนี้บนแพลตฟอร์มดังกล่าว เลือกแพ็กเกจเมื่อรุ่นเผยแพร่ระบุว่ารองรับระบบของคุณ

## ติดตั้งและเริ่มใช้งาน

1. บันทึกเอกสารที่เปิดอยู่และปิดรุ่นเก่าก่อนอัปเกรด
2. เรียกใช้ตัวติดตั้ง .exe ของ Windows ให้เสร็จ
3. เปิด VgoOffice จากทางลัดบนเดสก์ท็อปหรือเมนูเริ่ม

ตัวติดตั้งจัดเก็บทรัพยากรครั้งเดียว จึงไม่ต้องแตกไฟล์โปรแกรมแบบพกพาทุกครั้ง การคัดลอกเฉพาะ VgoOffice.exe จะขาดทรัพยากรที่ตัวแก้ไขต้องใช้

## อัปเกรดและการตั้งค่า

การอัปเกรดรักษารหัสการติดตั้งและโฟลเดอร์โปรไฟล์ Eoffice เดิม ชื่อโฟลเดอร์ Eoffice เป็นเรื่องปกติเพื่อความเข้ากันได้ ที่การตั้งค่า → ทั่วไป เลือกโหมดสว่าง มืด หรือตามระบบ พื้นหลังเริ่มต้นเป็นสีฟ้าเทาอ่อน สีเอกสารควบคุมแยกกัน

## รุ่นและโครงการ

การตั้งค่า → เกี่ยวกับ แสดงรุ่นที่ติดตั้งและลิงก์ VgoOffice หากมีประโยชน์สามารถให้ Star ได้ การอัปเดตขึ้นอยู่กับการตั้งค่าขณะสร้าง หากอัปเดตในแอปไม่ได้ ให้ตรวจสอบหน้ารุ่นเผยแพร่

[VgoOffice · Star](https://github.com/vgo1012/VgoOffice)

## บรรทัดคำสั่งและ AI

คำสั่งยังชื่อ genoffice การตั้งค่า → การผสานรวม แสดงพาธและการตั้งค่า เรียกใช้คำสั่งด้านล่างด้วยพาธนั้นหรือหลังเพิ่ม CLI ลงใน PATH

```sh
genoffice --version
```

ได้นำการเข้าสู่ระบบบัญชีแอปออกแล้ว ตั้งค่า API โมเดลของคุณ จุดเชื่อมต่อที่เข้ากันได้กับ OpenAI หรือ Codex CLI ที่ติดตั้งไว้ การยืนยันตัวตนและค่าบริการภายนอกเป็นเรื่องแยกกัน การแก้ไขบนเครื่องไม่ต้องมีบัญชี VgoOffice
