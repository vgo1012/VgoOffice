# Memasang VgoOffice

[Keluaran](https://github.com/vgo1012/VgoOffice/releases) — Gunakan pemasang yang dilampirkan pada keluaran. Halaman ini tidak bermaksud fail binari sudah diterbitkan di GitHub. Binaan setempat tidak ditandatangani tanpa kelayakan penandatanganan.

## Sebelum pemasangan

Edisi ini telah diuji pada Windows x64. Sasaran kod macOS dan Linux masih ada, tetapi edisi ini belum disahkan pada platform tersebut. Pilih pakej hanya jika keluarannya menyokong sistem pengendalian anda.

## Pemasangan dan permulaan

1. Simpan dokumen terbuka dan tutup versi terdahulu sebelum menaik taraf.
2. Jalankan pemasang .exe Windows hingga selesai.
3. Mulakan VgoOffice daripada pintasan desktop atau menu Mula.

Pemasang menyimpan sumber sekali, tanpa mengekstrak program mudah alih pada setiap permulaan. VgoOffice.exe sahaja tidak menyertakan sumber editor yang diperlukan.

## Naik taraf dan keutamaan

Naik taraf mengekalkan identiti pemasangan dan folder profil Eoffice. Nama folder Eoffice adalah normal demi keserasian. Dalam Tetapan → Umum, pilih rupa cerah, gelap atau sistem; latar lalai ialah biru kelabu muda. Warna dokumen dikawal berasingan.

## Versi dan projek

Tetapan → Perihal memaparkan versi terpasang dan pautan projek VgoOffice. Berikan Star jika membantu. Kemas kini bergantung pada konfigurasi binaan; semak halaman keluaran jika kemas kini dalam aplikasi tidak tersedia.

[VgoOffice · Star](https://github.com/vgo1012/VgoOffice)

## Baris perintah dan AI

Perintah serasi kekal genoffice. Tetapan → Integrasi menunjukkan laluan terpasang dan konfigurasi. Jalankan perintah di bawah menggunakan laluan itu atau selepas menambah CLI kepada PATH.

```sh
genoffice --version
```

Log masuk akaun aplikasi telah dibuang. Konfigurasikan API model anda, titik akhir serasi OpenAI atau Codex CLI terpasang. Pengesahan dan bayaran pihak ketiga tetap berasingan; suntingan setempat tidak memerlukan akaun VgoOffice.
