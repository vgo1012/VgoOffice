# VgoOffice — Suite da ufficio per desktop

VgoOffice riunisce editor di documenti, fogli di calcolo, presentazioni, PDF, Markdown e HTML in un’app desktop con interfaccia azzurra. I file vengono aperti, modificati e salvati localmente.

Questa edizione rimuove l’accesso all’account dell’app. L’IA usa un’API di modelli configurata dall’utente, un endpoint compatibile con OpenAI o un Codex CLI già installato. I servizi esterni possono richiedere credenziali e comportare costi.

L’installazione è stata verificata su Windows x64. I target di codice per macOS e Linux sono mantenuti, ma questa edizione non è stata verificata su tali piattaforme. Il download è disponibile solo quando una versione include un programma di installazione; questa pagina non conferma la pubblicazione di un file binario.
