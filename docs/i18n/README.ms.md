# VgoOffice — Ruang kerja pejabat desktop

VgoOffice menggabungkan editor dokumen, hamparan, pembentangan, PDF, Markdown dan HTML dalam aplikasi desktop dengan antara muka biru muda. Fail dibuka, disunting dan disimpan secara setempat.

Edisi ini membuang log masuk akaun aplikasi. AI menggunakan API model yang dikonfigurasi sendiri, titik akhir serasi OpenAI atau Codex CLI yang telah dipasang. Perkhidmatan pihak ketiga mungkin memerlukan kelayakan dan mengenakan bayaran.

Pemasangan telah diuji pada Windows x64. Sasaran kod macOS dan Linux masih ada, tetapi edisi ini belum disahkan pada platform tersebut. Muat turun hanya tersedia jika keluaran mengandungi pemasang; halaman ini tidak mengesahkan penerbitan fail binari.
