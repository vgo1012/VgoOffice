# VgoOffice — Настольная среда для офисных файлов

VgoOffice объединяет редакторы документов, таблиц, презентаций, PDF, Markdown и HTML в настольном приложении со светло-голубым интерфейсом. Открытие, редактирование и сохранение файлов выполняются локально.

В этой версии удалён вход в учётную запись приложения. Для ИИ используются настроенный вами API моделей, совместимый с OpenAI адрес или уже установленный Codex CLI. Внешним сервисам могут понадобиться собственные учётные данные; использование может быть платным.

Установка проверена на Windows x64. Целевые платформы macOS и Linux сохранены в исходном коде, но эта версия на них не проверена. Скачать установщик можно, только когда он прикреплён к выпуску; эта страница не подтверждает публикацию бинарного файла.
