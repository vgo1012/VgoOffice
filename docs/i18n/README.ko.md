# VgoOffice — 데스크톱 오피스 작업 공간

VgoOffice는 문서, 스프레드시트, 프레젠테이션, PDF, Markdown, HTML 편집기를 밝은 파란색 인터페이스의 데스크톱 앱으로 통합합니다. 파일 열기, 편집, 저장은 로컬 컴퓨터에서 처리합니다.

이 버전에서는 앱 계정 로그인을 제거했습니다. AI는 직접 설정한 모델 API, OpenAI 호환 엔드포인트 또는 이미 설치된 Codex CLI를 사용합니다. 외부 서비스에는 별도 인증과 비용이 필요할 수 있습니다.

Windows x64 설치와 실행을 실제로 검증했습니다. macOS와 Linux 소스 대상은 유지하지만 이 버전은 해당 플랫폼에서 검증하지 않았습니다. 릴리스에 설치 파일이 첨부되어야 다운로드할 수 있으며, 이 문서는 바이너리 공개를 보장하지 않습니다.
