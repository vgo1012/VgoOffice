# VgoOffice — Biurowe środowisko na komputer

VgoOffice łączy edytory dokumentów, arkuszy, prezentacji, PDF, Markdown i HTML w aplikacji komputerowej z jasnoniebieskim interfejsem. Otwieranie, edycja i zapisywanie plików odbywają się lokalnie.

W tej wersji usunięto logowanie do konta aplikacji. AI korzysta z własnej konfiguracji API modeli, punktu końcowego zgodnego z OpenAI lub wcześniej zainstalowanego Codex CLI. Usługi zewnętrzne mogą wymagać danych uwierzytelniających i naliczać opłaty.

Instalację sprawdzono na Windows x64. Cele kodu dla macOS i Linux pozostają, ale ta wersja nie została na nich zweryfikowana. Pobieranie jest możliwe tylko wtedy, gdy wydanie zawiera instalator; ta strona nie potwierdza opublikowania pliku binarnego.
