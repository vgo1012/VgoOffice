# VgoOffice — Suite bureautique de bureau

VgoOffice réunit des éditeurs de documents, feuilles de calcul, présentations, PDF, Markdown et HTML dans une application de bureau à l’interface bleu clair. Les fichiers sont ouverts, modifiés et enregistrés localement.

Cette édition supprime la connexion au compte de l’application. L’IA utilise une API de modèles configurée par l’utilisateur, un point de terminaison compatible avec OpenAI ou un Codex CLI déjà installé. Les services externes peuvent exiger des identifiants et être payants.

L’installation a été testée sur Windows x64. Les cibles de code macOS et Linux sont conservées, mais cette édition n’y a pas été validée. Le téléchargement est disponible seulement si une version contient un installateur ; cette page ne confirme pas la publication d’un binaire.
