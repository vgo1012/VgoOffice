# VgoOffice — סביבת עבודה משרדית למחשב

VgoOffice מאחד עורכים למסמכים, גיליונות, מצגות, PDF, Markdown ו-HTML באפליקציית מחשב עם ממשק תכלת. פתיחה, עריכה ושמירה של קבצים מתבצעות מקומית.

במהדורה זו הוסרה הכניסה לחשבון האפליקציה. יכולות AI משתמשות ב-API מודלים שתגדירו, בנקודת קצה תואמת OpenAI או ב-Codex CLI שכבר מותקן. שירותים חיצוניים עשויים לדרוש פרטי אימות ולגבות תשלום.

ההתקנה נבדקה ב-Windows x64. יעדי הקוד עבור macOS ו-Linux נשמרו, אך מהדורה זו לא אומתה בפלטפורמות האלה. הורדה זמינה רק כאשר מצורף מתקין לגרסה; עמוד זה אינו מאשר שקובץ בינארי כבר פורסם.
