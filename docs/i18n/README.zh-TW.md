# VgoOffice — 桌面辦公工作台

VgoOffice 將文件、試算表、簡報、PDF、Markdown 和 HTML 編輯器整合到一套桌面軟體中，支援本機開啟、編輯與儲存，並提供淺藍介面。

本版已移除軟體帳戶登入。AI 使用自行設定的模型 API、OpenAI 相容端點，或已安裝的 Codex CLI；第三方服務仍可能需要認證並收取費用。

目前已實際驗證 Windows x64 安裝版。macOS 和 Linux 原始碼目標仍在，但本定製版尚未在這些平台驗證。發布頁附有安裝包資產時才能下載，本文不代表已發布二進位版本。
