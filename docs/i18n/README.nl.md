# VgoOffice — Office-werkruimte voor de desktop

VgoOffice brengt editors voor documenten, spreadsheets, presentaties, PDF, Markdown en HTML samen in een desktopapp met een lichtblauwe interface. Bestanden worden lokaal geopend, bewerkt en opgeslagen.

In deze editie is aanmelden bij een app-account verwijderd. AI gebruikt een zelf ingestelde model-API, een OpenAI-compatibel endpoint of een al geïnstalleerde Codex CLI. Externe diensten kunnen eigen inloggegevens vereisen en kosten in rekening brengen.

De installatie is getest op Windows x64. De broncodedoelen voor macOS en Linux blijven bestaan, maar deze editie is daar niet gevalideerd. Downloaden kan alleen als een release een installatiebestand bevat; deze pagina bevestigt niet dat er al een binair bestand is gepubliceerd.
