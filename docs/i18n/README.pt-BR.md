# VgoOffice — Suíte de escritório para desktop

O VgoOffice reúne editores de documentos, planilhas, apresentações, PDF, Markdown e HTML em um aplicativo para desktop com interface azul-clara. A abertura, edição e gravação dos arquivos ocorrem localmente.

Esta edição remove o login da conta do aplicativo. A IA usa uma API de modelos configurada pelo usuário, um endpoint compatível com OpenAI ou um Codex CLI já instalado. Serviços externos podem exigir credenciais e cobrar pelo uso.

A instalação foi testada no Windows x64. Os alvos de código para macOS e Linux continuam no repositório, mas esta edição não foi validada neles. Só é possível baixar quando uma versão inclui o instalador; esta página não confirma uma publicação binária.
