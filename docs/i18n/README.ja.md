# VgoOffice — デスクトップのオフィス作業環境

VgoOffice は文書、表計算、プレゼンテーション、PDF、Markdown、HTML の編集を一つのデスクトップアプリにまとめています。淡い青の画面で、ファイルの読み込み、編集、保存をローカルで行えます。

この版ではアプリのアカウントログインを削除しています。AI は自分で設定したモデル API、OpenAI 互換エンドポイント、または導入済みの Codex CLI を使用します。外部サービスには別途認証や利用料金が必要な場合があります。

Windows x64 のインストールと動作を実際に検証しています。macOS と Linux のソース対象は残していますが、この版では未検証です。リリースにインストーラーが添付された場合にダウンロードできます。このページはバイナリの公開済みを意味しません。
