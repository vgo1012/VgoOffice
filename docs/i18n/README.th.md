# VgoOffice — พื้นที่ทำงานเอกสารบนเดสก์ท็อป

VgoOffice รวมตัวแก้ไขเอกสาร ตารางคำนวณ งานนำเสนอ PDF, Markdown และ HTML ไว้ในแอปเดสก์ท็อปที่มีพื้นหลังสีฟ้าอ่อน การเปิด แก้ไข และบันทึกไฟล์ทำบนเครื่องของคุณ

รุ่นนี้นำการเข้าสู่ระบบบัญชีของแอปออก AI ใช้ API โมเดลที่คุณตั้งค่าเอง จุดเชื่อมต่อที่เข้ากันได้กับ OpenAI หรือ Codex CLI ที่ติดตั้งไว้แล้ว บริการภายนอกอาจต้องใช้ข้อมูลรับรองและมีค่าใช้จ่าย

ได้ตรวจสอบการติดตั้งบน Windows x64 แล้ว โค้ดยังมีเป้าหมายสำหรับ macOS และ Linux แต่รุ่นปรับแต่งนี้ยังไม่ได้ตรวจสอบบนแพลตฟอร์มเหล่านั้น ดาวน์โหลดได้เมื่อรุ่นเผยแพร่แนบตัวติดตั้งเท่านั้น หน้านี้ไม่ได้ยืนยันว่าเผยแพร่ไฟล์โปรแกรมแล้ว
