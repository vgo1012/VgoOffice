# VgoOffice — Suite de oficina de escritorio

VgoOffice reúne editores de documentos, hojas de cálculo, presentaciones, PDF, Markdown y HTML en una aplicación de escritorio con una interfaz azul clara. Los archivos se abren, editan y guardan localmente.

Esta edición elimina el inicio de sesión de la cuenta de la aplicación. La IA utiliza una API de modelos configurada por el usuario, un servidor compatible con OpenAI o un Codex CLI ya instalado. Los servicios externos pueden requerir credenciales y generar costes.

La instalación se ha probado en Windows x64. Se mantienen los destinos de código para macOS y Linux, pero esta edición no se ha validado en ellos. La descarga solo está disponible cuando una versión incluye un instalador; esta página no confirma que ya se haya publicado.
