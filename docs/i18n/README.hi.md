# VgoOffice — डेस्कटॉप ऑफिस कार्यक्षेत्र

VgoOffice दस्तावेज़, स्प्रेडशीट, प्रस्तुतियाँ, PDF, Markdown और HTML संपादकों को हल्के नीले इंटरफ़ेस वाली एक डेस्कटॉप ऐप में जोड़ता है। फ़ाइलें स्थानीय कंप्यूटर पर खोली, संपादित और सहेजी जाती हैं।

इस संस्करण में ऐप खाते का लॉगिन हटा दिया गया है। AI आपके द्वारा कॉन्फ़िगर किए गए मॉडल API, OpenAI-संगत एंडपॉइंट या पहले से स्थापित Codex CLI का उपयोग करता है। बाहरी सेवाओं को अलग प्रमाण-पत्रों की आवश्यकता हो सकती है और उनका उपयोग शुल्क वाला हो सकता है।

इंस्टॉलेशन का Windows x64 पर परीक्षण हुआ है। macOS और Linux के स्रोत लक्ष्य बने हुए हैं, लेकिन इस संस्करण का उन पर सत्यापन नहीं हुआ है। डाउनलोड तभी उपलब्ध होगा जब किसी रिलीज़ में इंस्टॉलर जुड़ा हो; यह पृष्ठ बाइनरी प्रकाशित होने की पुष्टि नहीं करता।
