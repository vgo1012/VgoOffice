# VgoOffice — Office-Arbeitsplatz für den Desktop

VgoOffice vereint Editoren für Dokumente, Tabellen, Präsentationen, PDF, Markdown und HTML in einer Desktop-App mit hellblauer Oberfläche. Dateien werden lokal geöffnet, bearbeitet und gespeichert.

Diese Ausgabe entfernt die Anmeldung bei einem App-Konto. KI nutzt eine selbst konfigurierte Modell-API, einen OpenAI-kompatiblen Endpunkt oder eine bereits installierte Codex CLI. Externe Dienste können Zugangsdaten erfordern und Kosten verursachen.

Die Installation wurde unter Windows x64 geprüft. Quellcode-Ziele für macOS und Linux bleiben erhalten, diese Ausgabe wurde dort aber nicht validiert. Ein Download ist erst verfügbar, wenn eine Veröffentlichung ein Installationspaket enthält; diese Seite bestätigt keine bereits veröffentlichte Binärdatei.
