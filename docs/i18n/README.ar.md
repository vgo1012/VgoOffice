# VgoOffice — مساحة عمل مكتبية

يجمع VgoOffice محررات المستندات والجداول والعروض التقديمية وملفات PDF وMarkdown وHTML في تطبيق مكتبي بواجهة زرقاء فاتحة. يتم فتح الملفات وتحريرها وحفظها محليًا.

أزيل تسجيل الدخول إلى حساب التطبيق في هذا الإصدار. يستخدم الذكاء الاصطناعي واجهة نماذج تضبطها بنفسك، أو نقطة اتصال متوافقة مع OpenAI، أو Codex CLI المثبت مسبقًا. قد تحتاج الخدمات الخارجية إلى بيانات اعتماد وقد تفرض رسومًا.

تم التحقق من التثبيت على Windows x64. تبقى أهداف الشفرة لنظامي macOS وLinux، لكن لم يتم التحقق من هذا الإصدار عليهما. التنزيل متاح فقط عندما تتضمن صفحة إصدار ملف تثبيت؛ هذه الصفحة لا تؤكد نشر ملف تنفيذي بالفعل.
