# VgoOffice — Kancelářské prostředí pro počítač

VgoOffice spojuje editory dokumentů, tabulek, prezentací, PDF, Markdown a HTML v desktopové aplikaci se světle modrým rozhraním. Otevírání, úpravy a ukládání souborů probíhají místně.

Tato verze odstraňuje přihlášení k účtu aplikace. AI používá vlastní nastavení API modelů, koncový bod kompatibilní s OpenAI nebo již nainstalované Codex CLI. Externí služby mohou vyžadovat přihlašovací údaje a účtovat poplatky.

Instalace byla ověřena na Windows x64. Cíle zdrojového kódu pro macOS a Linux zůstávají, ale tato verze na nich nebyla ověřena. Stahování je dostupné pouze tehdy, když vydání obsahuje instalátor; tato stránka nepotvrzuje zveřejnění binárního souboru.
