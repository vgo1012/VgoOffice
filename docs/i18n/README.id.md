# VgoOffice — Ruang kerja kantor desktop

VgoOffice menyatukan editor dokumen, lembar kerja, presentasi, PDF, Markdown, dan HTML dalam aplikasi desktop dengan antarmuka biru muda. Berkas dibuka, diedit, dan disimpan secara lokal.

Edisi ini menghapus login akun aplikasi. AI menggunakan API model yang Anda konfigurasi sendiri, endpoint kompatibel OpenAI, atau Codex CLI yang sudah terpasang. Layanan pihak ketiga mungkin memerlukan kredensial dan mengenakan biaya.

Instalasi telah diuji pada Windows x64. Target kode macOS dan Linux tetap tersedia, tetapi edisi ini belum divalidasi di sana. Unduhan hanya tersedia jika rilis menyertakan penginstal; halaman ini tidak menyatakan bahwa berkas biner sudah diterbitkan.
