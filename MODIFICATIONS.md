# VgoOffice modifications

VgoOffice is a modified distribution of the GenOffice open-source core from
https://github.com/genspark-ai/genoffice, based on upstream snapshot
fc754f7a90619289942602ebcce68bd57a90515c. The original copyright attribution,
Apache-2.0 license, NOTICE and bundled component licenses are retained.

The VgoOffice edition changes desktop branding, icons, colors and product
information; removes application-account login and account-dependent home
features; preserves configurable API and CLI access; fixes Unicode decoding of
Windows default-program names; packages the native spreadsheet and Windows OCR
helpers; and redirects project, issue, download and Star links to
https://github.com/vgo1012/VgoOffice.

Public readmes and user-facing descriptions document this edition's actual
behavior. Compatibility identifiers such as the `genoffice` command,
`@genoffice/*` workspaces, `GENOFFICE_*` environment variables, document-private
format markers and font family identifiers remain unchanged. The Windows
upgrade identity `com.eoffice.app` and existing Eoffice profile remain stable to
preserve user settings.

Files modified for this edition are identified by the VgoOffice commits and the
modification notices in source and documentation. New logo assets are supplied
for this edition. The `ee/` directory has a separate license and currently
contains only its license and a placeholder readme.
